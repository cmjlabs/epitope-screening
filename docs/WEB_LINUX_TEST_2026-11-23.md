## 结果包与筛选顺序

`完整结果包 ZIP` 保留实际任务文件，而非仅最终 Excel。完整解压后先打开 `先看这里.html`，分组查看原始输入、IEDB 原生预测、阈值阶段、最终结果和运行记录。

MHC-I / II 各自按以下顺序累计筛选：标准化原表 → IC50 → rank → score 下限 → score 上限 → HLA 拆分去重。窗口阶段依次导出全窗口 → I 类覆盖率通过 → II 类覆盖率通过（即最终候选）。`filter_summary.csv` 与 Excel 同名工作表记录每一步的规则、输入和保留行数。每个零行阶段也保留表头。

ZIP 原生流式下载使用仅本机会话可签发、60 秒过期、单次使用的下载链接；不把整个大包加载到浏览器 JavaScript 内存。包内不包含 IEDB 模型权重或 Python 环境。
