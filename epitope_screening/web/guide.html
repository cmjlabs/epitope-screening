Linux 网页版：从下载到第一份报告

适用：Ubuntu 22.04 / 24.04 或兼容的 Debian 桌面，x86_64 / amd64。日常操作都在浏览器中完成。无需安装 Docker、Conda 或自行配置 Python，也无需作者电脑、原网站在线。

1．下载正确的包

  1. 打开 GitHub Releases。仓库目前为 Private；看见 404 时，先登录有读取权限的账号。普通访客还不能直接下载，作者需要授予读取权限或另行决定公开发布。
  2. 在 Assets 中下载 EpitopeScreening-v0.4.0b1-Web-Linux-x64.tar.gz。不要选择页面自动提供的 Source code (zip)；那是开发者源码，需要另外准备运行环境。
  3. 用文件管理器右键 → “提取到此处”。进入 EpitopeScreening-Web 文件夹。
  4. 保留里面的全部文件，尤其是 _internal。可以把整个文件夹移动到“文档”或其他位置。日后更新时，也应替换整个程序文件夹。

2．启动与立即体验

  1. 双击 Start-Web。浏览器应自动打开 http://127.0.0.1:某个端口/。
  2. 如果提示没有执行权限：右键 Start-Web → 属性 → 权限 → 勾选“允许作为程序执行”。某些 Linux 文件管理器不允许双击可执行文件；可在此文件夹“在终端中打开”，只需输入 ./Start-Web 并回车。
  3. 如果浏览器未自动打开，在终端运行 ./Start-Web，复制程序打印的完整地址到浏览器。地址中的会话信息只用于本机连接，请不要分享。
  4. 点击 试用离线演示。几秒后应显示 21 个扫描窗口、21 个候选窗口，并出现“下载 Excel 报告”。下载后用 Excel / LibreOffice 打开。
  5. 演示使用人工数据和演示阈值，只验证程序、网页和导出流程，不是 IEDB 真实预测或科学结论。

先看这里.html 可以双击阅读离线说明；正式运行请启动 Start-Web。浏览器页面负责操作，Start-Web 负责调用本机预测器。单独 HTML 无法启动本地 IEDB 程序。

3．首次配置本地 IEDB（只需一次）

  1. 在左侧进入 首次配置，检查平台、磁盘和组件。建议至少预留 12 GB 可用空间。
  2. 打开页面中的 IEDB 官方下载与许可说明，确认适用的使用条件和自己的使用权限，然后勾选对应确认。
  3. 如缺少组件，勾选允许系统授权安装。程序只安装 tcsh、gawk、Perl、R 和证书组件。Ubuntu / Debian 桌面将通过系统的 pkexec 授权窗口请求管理员权限；不要把管理员密码输入网页。
  4. 点击 下载并配置官方工具。程序自动下载固定版本的 TC1 / TC2，校验 SHA256、解压、准备独立 Python 3.11 和预测依赖，并验证入口。无需手动选择 Python。
  5. 两个模型包合计约 2.4 GB（十进制），首次还会下载 Python 和依赖；耗时取决于网络。保持电脑联网、启动程序运行，并留意系统授权窗口。网页底部可展开配置日志。
  6. 出现 配置完成，可以开始本地分析 后即可使用。以后相同用户启动新版程序仍复用这些模型，不需要再次下载。正式本地预测时可断网。

如果你已从官方下载对应的原始压缩包，可展开“我已经下载了官方工具包”，选择 TC1 v0.2-beta 和 TC2 v0.2.3-beta 的 .tar.gz，再点“导入并配置”。不要解压、改动压缩包，也不要使用其他版本；程序会校验版本对应的 SHA256。此方式仍需要联网准备首次 Python / 依赖，除非它们已经配置。

自动安装组件目前面向 Ubuntu / Debian；没有 pkexec 的精简系统需要管理员先安装所列组件。软件不会自动索取密码或后台提权。首次配置支持下载断点续传，完整下载文件校验后复用；失败后可重试。不要移动已安装的数据目录。

4．先用真实的小例子试跑

  1. 回到 新建分析，选择 本地预测。
  2. 点击 载入公开试跑序列：载入 32 aa 的公开 LCMV 蛋白，并切换到每类一个 HLA 的快速试跑面板。
  3. 输入任务名，例如“首次本地试跑”。保留其他筛选参数，点击 开始分析。
  4. 日志中应出现本地 IEDB 批次信息，完成后可下载 Excel。
  5. 默认覆盖率要求两类分别达到 0.8；一个 HLA 的快速试跑通常没有候选，属于预期。流程完成并导出全窗口报告才是这一步的检查目标。不要为了增加候选而把试跑参数直接当成论文参数。

5．分析自己的蛋白

  1. 选择单蛋白 FASTA，或粘贴氨基酸序列。不要输入 DNA/RNA 序列或多条蛋白合并文件。
  2. 选择完整 HLA 面板或自行指定 HLA，核对肽长。默认 MHC-I 8–14 aa，MHC-II 15 aa。
  3. 核对窗口长度（默认 20–30 aa）、人群（默认 World）和覆盖率（默认两类分别 ≥ 0.8）。覆盖率取值为 0–1，0.8 代表 80%。
  4. 展开“高级参数”，核对 IC50、rank、免疫原性 score、MHC-I 等位基因专属 cutoff。不要把 BA、EL、rank、免疫原性 score 混为一个指标。界面支持导入、导出两种独立的参数 JSON。
  5. 点击 开始分析。默认同时运行两个本地预测任务，避免无控制地占用 CPU。蛋白越长、HLA 和肽长范围越多，耗时越长。本地预测消除了官方 API 排队，但仍需要真实计算。
  6. 完成后下载 Excel 或候选 CSV；任务记录中可再次打开和下载。

当前模型为 NetMHCpan BA 与 NetMHCIIpan BA 4.3，并计算对应免疫原性评分；CD4Episcore 路径仅对 15 aa 验证过。本文软件默认参数尚未与历史论文参数核定。

6．阅读和保存报告

  • selected_windows：达到阈值的候选长肽、来源位置、对应 HLA 和两类人群覆盖率。
  • all_windows：全部扫描窗口；没有候选时优先查看此表。
  • mhci_filtered / mhcii_filtered：通过阈值的短表位。
  • 任务目录还保存原始预测、FASTA、参数、模型签名及运行记录，便于追溯。

模型、上传文件、任务和原始结果的默认位置为 ~/.local/share/epitope-screening/，页面“首次配置”会显示这台电脑的实际绝对路径。jobs/<任务编号>/output/ 存放任务输出，网页下载按钮只是另存一份报告。请备份整个数据目录；关闭网页不会删除结果。

7．其他模式、恢复和退出

  • IEDB 在线预测：不必安装本地模型；需要联网，并在页面明确确认将序列发送到 IEDB 官方服务器。速度受官方排队影响。没有自建服务器，也不依赖作者电脑。
  • 导入已有预测表：提供 FASTA、MHC-I、MHC-II 两张表，直接本地筛选。表格必须包含序列、HLA、位置以及所需 IC50、rank、score；缺失/非数值 score 会报错。格式参见 INPUTS.md。
  • 取消与恢复：点击“取消分析”后等待停止。打开“任务记录”，选择原预测任务，再点“恢复”。程序复用已完成且校验有效的批次。恢复时保持同一任务的序列、模型和参数。需要改参数时新建分析。导入表模式可直接新建分析。
  • 关闭浏览器：本机程序仍在运行，预测继续；再次双击 Start-Web 会重开页面。
  • 退出程序：先取消或等分析结束，再点右上角“退出程序”。首次配置期间请等配置结束。不要直接关机；意外中断后可在原任务记录中恢复预测。

8．遇到问题

现象处理
GitHub 显示 404登录有此 Private 仓库读取权限的账号；由作者授予权限。
下载后看不到 Start-Web很可能下载了 Source code；改下载 Assets 中的 Web-Linux-x64.tar.gz。
双击打不开检查执行权限、x86_64 架构，必要时从终端执行 ./Start-Web 查看错误；不支持 ARM / 过旧 glibc。
网页“未连接”保持 Start-Web 运行，再次双击启动以获取当前会话地址；不要使用旧书签。
首次配置不动展开配置日志，查看是否等待系统授权、官方下载或 Python 依赖下载；检查网络。
缺少 pkexec 或 apt-get自动配置面向 Ubuntu/Debian 桌面；请管理员先安装系统组件，其他发行版使用手动配置路径。
模型校验失败重新下载页面所列官方固定版本；不要使用来历不明或已修改的工具包。
磁盘空间不足清理空间后重试，不要随意删除 jobs 中的原始记录。
结果为零查看 all_windows、输入及两类覆盖率；单 HLA 测试通常无法达到 0.8。
Windows 本地预测本 Linux 包不适用；现有 Windows 版提供 API / 导入表模式，本地 IEDB 尚未接入。

网页服务仅监听本机 127.0.0.1，无需开放防火墙或端口转发。它用于个人电脑操作，不用于部署公开网站。
