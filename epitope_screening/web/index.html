使用说明

不需要了解命令行，也不需要启动作者的电脑或网站。

打开完整的逐步新手手册 ↗

第一次打开

  1. 在 GitHub Releases 下载 Linux 网页版压缩包，完整解压。请保留 _internal 文件夹。若下载页显示 404，请先登录有仓库读取权限的 GitHub 账号。
  2. 双击 Start-Web。浏览器会自动打开本机操作页面。如系统要求权限，在文件属性中勾选“允许作为程序执行”。不要把单独的 HTML 当成预测器启动。
  3. 先点击“试用离线演示”，确认能生成和下载报告。演示数据是人工构造的，不用于论文结论。
  4. 要从 FASTA 本地预测，进入“首次配置”，阅读官方许可，按提示确认后点击“下载并配置官方工具”。需要安装系统组件时，在系统弹出的窗口授权。

开始正式分析

  1. 选择运行方式。本地预测配置一次后可断网；IEDB 在线需要联网并确认发送序列；导入表模式需要已有两张预测表。
  2. 输入一个任务名称，选择单蛋白 FASTA，或者粘贴氨基酸序列。不要上传基因组或多条蛋白的合并文件。
  3. 核对 HLA 面板、肽长、窗口、人群及阈值。默认窗口 20–30 aa，两类覆盖率分别至少 0.8。快速试跑只有每类一个 HLA，仅用于验证流程。
  4. 点击“开始分析”。大蛋白、多 HLA、多肽长的任务可能计算较久，每批完成后会更新进度；运行日志保留详细状态。
  5. 完成后优先下载完整结果包 ZIP，解压后阅读包内说明；也可单独下载 Excel。selected_windows 是候选，all_windows 是全部窗口，另外两张表为筛选后的 MHC-I/MHC-II 表位。覆盖率为 0–1。

常见问题

关闭网页后，任务还在吗？

关闭浏览器不会删除结果，也不会关闭本机程序。再次双击 Start-Web 可重新打开页面。运行或首次配置时请保留启动程序；需要结束时先取消任务，再点右上角“退出程序”。

为什么没有候选？

无候选可能是当前阈值下的真实结果，尤其是单 HLA 试跑。下载全窗口报告检查输入、参数及两类覆盖率。默认参数不代表历史论文参数，软件运行成功不等于历史结果已经复现。

如何恢复中断任务？

进入“任务记录”，打开原预测任务，点击“恢复”。已完成且校验有效的预测批次会复用。在线与本地任务不能混合恢复，不能同时修改模型、HLA、FASTA 和筛选参数。

文件在哪里？需要作者电脑在线吗？

文件保存在“首次配置”显示的本机数据位置，不依赖作者服务器。程序更新后仍使用相同数据目录。在线模式只向 IEDB 官方服务发送必要预测输入。

安装失败怎么办？

打开配置日志查看具体原因，检查网络、磁盘空间和系统授权。Ubuntu/Debian 桌面通常使用 pkexec 弹出授权窗口；若系统不提供图形授权，请管理员先安装页面列出的系统组件。断网时无法进行首次下载。

Windows 能用这个本地包吗？

当前一键本地配置支持 Linux x86_64。Windows 可继续使用现有在线/导入表版本；Linux 预测器不能由纯 HTML 直接变成 Windows 程序。

这份说明与页面均包含在程序中。日常本地操作不需要加载任何外部网页资源。
