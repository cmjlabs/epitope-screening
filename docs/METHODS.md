# 计算方法与版本约定

1. IC50 ≤ 阈值；MHC-I 可使用内置或指定的 allele-specific cutoff。
2. percentile ≤ rank 阈值。
3. 免疫原性评分 ≥ 下限且 ≤ 上限；可显式选择 MHC-I 严格 > 下限，用于后续历史方法核对。
4. HLA 按 `/`、`,`、`;` 拆分，补全 `HLA-`，精确去重。MHC-II 两条链的拆分规则继承网站现有逻辑；不将其擅自替换为新的异二聚体模型。
5. 遍历所有指定长度、所有合法起点的窗口；只有完全包含在窗口内的表位参与该窗口计算。
6. 分别调用本地 IEDB Population Coverage 3.0.2 频率快照，计算 MHC-I / II 覆盖率。仅输出总覆盖率，不输出每个表位的命中分布。总覆盖率按该类 HLA 并集缓存，不跨分析任务复用缓存。
7. 输出覆盖率保留浮点精度。候选条件为 `round(mhc1_coverage, 4) >= threshold` 且 `round(mhc2_coverage, 4) >= threshold`。Excel 中的 0.8 表示 80%。

无表位窗口的覆盖率为 0；计算异常会中止并标记失败，不伪装成 0。若某窗口的全部 HLA 都无频率数据则报错；部分 HLA 无数据时沿用第三方计算器对可用数据的处理方式，并把缺失项写入运行记录。

`mhc1_count` / `mhc2_count` 是去重后的 peptide–coordinate–allele 记录数，不是唯一肽段数量。`combined_score` 是两类覆盖率的平均值，不是联合人群覆盖率，也不是免疫保护概率。

整理版与旧网站实现差异：拒绝多记录 FASTA；明确列验证和缺失值错误；保存每次运行参数与哈希；显式报错替代 cutoff 文件缺失时静默回退；标准化去重；中间步骤统一使用 CSV；窗口输出为标量列，避免把 DataFrame 对象写入 Excel 单元格。本版尚未与历史研究结果做等价性认证。
